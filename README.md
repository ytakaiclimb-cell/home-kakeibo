# さっと家計簿

ホーム画面から開いて、**残高が一目で分かる**・**ワンタップで支出を記録できる**家計簿です。

- インストール不要のWebアプリ（PWA）。ホーム画面に追加すると普通のアプリのように起動します
- オフラインでも動きます
- データはブラウザの `localStorage` に保存され、端末の外には出ません（サーバーもアカウントもありません）

## 画面

| 残高 | ワンタップ記録 | テンキー |
| --- | --- | --- |
| 今月の残り・使った額・予算・進捗バー・「1日あたりいくら使えるか」 | カテゴリのタイルを押すだけで既定額を記録（取り消し付き） | 任意の金額をカテゴリ付きで記録 |

## 使い方

1. スマホのブラウザで公開URLを開く
2. **iOS / Safari**: 共有ボタン → 「ホーム画面に追加」
   **Android / Chrome**: メニュー → 「アプリをインストール」または「ホーム画面に追加」
3. 右上の歯車から、今月の予算とカテゴリごとのワンタップ金額を設定
4. あとはタイルを押すだけ。押した直後に下に出る「取り消す」で間違いを戻せます

Android ではホーム画面のアイコンを長押しすると、「食費を記録」などのショートカットが出ます。選ぶとアプリが開いた瞬間にその金額が記録されます。

## 公開する（GitHub Pages）

静的ファイルだけなので、そのまま置けば動きます。

1. GitHub のリポジトリ設定 → Pages → Source を `Deploy from a branch`、ブランチをこのブランチ（または `main`）の `/ (root)` に設定
2. 発行されたURLをスマホで開く

Service Worker を使うため、**HTTPS か `localhost`** で開く必要があります。

## 手元で動かす

```sh
python3 -m http.server 8777
# → http://localhost:8777/
```

## ファイル構成

```
index.html              画面の構造
styles.css              スタイル（ダークモード対応）
app.js                  記録・集計・保存・UIの制御
manifest.webmanifest    ホーム画面への追加とショートカットの定義
sw.js                   オフライン用のキャッシュ
icons/                  アプリアイコン（192 / 512 / maskable）
tools/generate-icons.py アイコンを作り直すスクリプト（依存ライブラリなし）
```

## データについて

- 保存先はこの端末のブラウザのみです。ブラウザのデータを消すと記録も消えます
- 設定画面の「データを書き出す」でJSONとして保存できます
- 残高・履歴は「今月分」を対象に集計しています。月が替わると自動的にリセットされます（過去の記録は書き出しJSONに残ります）

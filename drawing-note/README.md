# お絵かきノート（Android）

無限に広がるキャンバスに描ける、お絵かき・手書きノートアプリです。

## できること

| 機能 | 操作 |
| --- | --- |
| 用紙 | 白紙 / ラインノート / グリッド（新規作成時、または上部の用紙ボタンで切り替え） |
| ズーム・移動 | 2本指でピンチイン・ピンチアウト、2本指ドラッグでスクロール。キャンバスは上下左右どこまでも続きます |
| ペン | ペン / ブラシ（速さで太さが変わる筆） / ぼかし（ふんわりした線）。下のスライダーで太さを変更 |
| 消しゴム | 1線消し（触れた線をまるごと消す） / 消しゴム（こすった部分だけ消す） |
| 戻る・進む | 上部の矢印ボタン |
| 直線・図形 | 直線、四角・円・三角・矢印 |
| バケツ | パレットの色を上へドラッグ（または長押し）してキャンバスにドロップすると、その場所を塗りつぶし。バケツツールでタップしても塗れます |
| テキスト | テキストツールでタップして入力。既存の文字をタップすると編集・削除 |
| その他 | ノートは複数作成でき自動保存。上部の保存ボタンで PNG を「ピクチャ/DrawingNote」に書き出し |

Android 10 以上に対応しています。

## APK の入手

`drawing-note/` 以下を push すると GitHub Actions（`.github/workflows/android.yml`）が APK をビルドし、
リリース **drawing-note-latest** に `DrawingNote.apk` を置きます。
Android 端末でリリースページを開き、APK をダウンロードしてインストールしてください
（初回は「提供元不明のアプリ」のインストール許可が必要です）。

APK は `app/signing.keystore` の固定鍵で署名しているので、新しいビルドをそのまま上書きインストールできます。
この鍵はリポジトリで公開しているため、ストア配布用には別の鍵を用意してください。

## 手元でビルドする場合

Android SDK を入れた環境で:

```sh
cd drawing-note
./gradlew assembleRelease
# app/build/outputs/apk/release/app-release.apk
```
